# Contributing to Soloist

Thank you for contributing to Soloist.

## Commit messages

All new commits must follow the [Conventional Commits 1.0.0](https://www.conventionalcommits.org/en/v1.0.0/) specification:

```text
<type>: <short description>
```

Use a concise, imperative description. Common types include:

- `feat`: a new user-facing feature.
- `fix`: a bug fix.
- `docs`: documentation-only changes.
- `test`: tests added or changed.
- `refactor`: code restructuring with no behavior change.
- `chore`: maintenance work.

Examples:

```text
feat: add keyboard shortcut for focus mode
fix: restore hidden apps when Soloist quits
docs: clarify installation steps
```
